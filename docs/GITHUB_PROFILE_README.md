## 🚀 创建步骤

### 1. 创建同名仓库
1. 访问 <https://github.com/new>
2. **Repository name**：必须和你的用户名**完全一样**（如 `your-name/your-name`）
3. **Public** + **Add a README file**
4. Create repository

### 2. 编辑 README.md
- 在新建的仓库页面点击 ✏️ 编辑 README.md
- 把上面模板中的 `<your-name>` 全部替换为你的实际用户名
- 把 `<your-email@example.com>` 改成真实邮箱
- 把 `<https://ai-me-xxxx.vercel.app>` 改成你部署后的 URL
- **Commit changes**

### 3. 验证
访问 `https://github.com/<your-name>`，应该能看到 Profile README 渲染。
